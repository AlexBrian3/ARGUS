# 👁️ ARGUS: The Hundred-Eyed Builder Intelligence Engine

> *"The giant who never sleeps, watching every signal across every ecosystem."*  
> **ARGUS** is an autonomous information-advantage intelligence engine designed to discover high-value technical opportunities before they become crowded, evaluate asymmetric expected value (`HackScore`), reverse-engineer sponsor playbooks and historical winner patterns, and continuously alert builders via CLI, Telegram, and Generative UI dashboards.

---

## 🏛️ The 10 ARGUS Engines

1. **Engine 1 — Opportunity Scout**: Multi-tier ingestion (Tier 0: GitHub repos, RFCs; Tier 1: Foundation blogs, dev portals; Tier 2: ETHGlobal, Colosseum, DoraHacks, Devpost).
2. **Engine 2 — Ecosystem Radar**: Dynamic momentum tracking across Solana, Base, Monad, MegaETH, Ethereum, Sui, ZK, and Decentralized AI.
3. **Engine 3 — Sponsor Intelligence**: Persistent profiles reverse-engineering what sponsors repeatedly reward and predicting upcoming appearances.
4. **Engine 4 — Historical Winner Analysis**: 50+ project corpus dissecting winning execution vs common losing pitfalls.
5. **Engine 5 — Opportunity Scoring (`HackScore /100`)**: Transparent EV formulas estimating serious competitors, prize-to-competitor ratio, and placement probabilities.
6. **Engine 6 — User Fit (`Skill Match /100`)**: Calibrated to your Staff AI Platform background (FastAPI, vLLM, LangGraph, Qdrant) and `hackathon-launchpad` assets.
7. **Engine 7 — Early Signal Alerts**: 3-level triage (🔴 Level 1 First Signal, 🟠 Level 2 Confirmed, 🟢 Level 3 Actionable Edge) with cryptographic deduplication.
8. **Engine 8 — Social Content Intelligence**: Evaluates discovery novelty and writes viral technical content drafts.
9. **Engine 9 — Trend Detection**: Tracks emerging technical narratives (x402 payments, verifiable inference, parallel EVM) based on developer traction.
10. **Engine 10 — Persistent Memory**: SQLite-backed historical intelligence that grows compounding advantages after every event.

## ⚡ Quickstart

### 1. Run Complete Intelligence Scan
```bash
python -m brain.cli scan
```
Performs a full sweep across monitored sources, re-evaluates all 10 engines, checks alert selectivity, and refreshes the Generative UI dashboard.

### 2. View Active Level 3 Actionable Edge Opportunities
```bash
python -m brain.cli edge
```
Displays mispriced, high-EV opportunities with custom non-generic build directions leveraging your `hackathon-launchpad` and AI Platform assets.

### 3. Check Ecosystem Momentum Radar
```bash
python -m brain.cli radar
```
Inspects the Momentum Leaderboard (scores /100 and trajectory `↑ accelerating`, `→ stable`, `↓ declining`) and flags stealth momentum before major hackathons.

### 4. Reverse-Engineer a Sponsor
```bash
python -m brain.cli sponsor world
python -m brain.cli sponsor dynamic
python -m brain.cli sponsor pyth-network
```
Displays persistent Sponsor Intelligence Cards: predictability scores, what they repeatedly reward, features winners frequently use vs rarely used by competitors, and proactive preparation playbooks.

### 5. Study Historical Winner & Losing Patterns
```bash
python -m brain.cli winners
```
Surfaces recurring winning patterns, common losing mistakes, oversaturated ideas, and high-leverage underexplored niches.

### 6. Telegram Bot Integration
```bash
# Verify bot connection
python -m brain.cli telegram test

# Push all active Level 3 Edge alerts to Telegram
python -m brain.cli telegram push

# Send an intelligence summary digest
python -m brain.cli telegram summary
```

### 7. Generate Social Content Alpha
```bash
python -m brain.cli content colosseum-crypto-worlds-fair-2026
```
Outputs production-ready X/Twitter 5-post threads, TikTok/Reels scripts, YouTube Shorts scripts, and LinkedIn thought-leadership posts.

### 8. Launch Interactive Dashboard
Open `dashboard/dashboard.html` in your browser, or view the Generative UI widget directly in Antigravity chat.

## 🕒 Autonomous Hourly Daemon

To run the daemon locally:
```bash
# Single hourly check
python -m brain.daemon

# Continuous hourly loop
python -m brain.daemon --continuous
```
Or use the Antigravity `/schedule` command or native schedule tool.
